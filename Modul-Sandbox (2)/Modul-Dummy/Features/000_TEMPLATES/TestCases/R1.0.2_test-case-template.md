Formatting rules (explicit example):

- Every numbered step must immediately contain the label `[Test Step]` followed by an HTML `<br>` and then the step text on the next line. No extra spaces or TABs are allowed between the step number and the `[Test Step]` label.
- Immediately before the `[Expected Result]` label a literal TAB character (U+0009) must be present; after `[Expected Result]` insert an HTML `<br>` and then the result text on the next line.

Example (literal representation):

1. [Test Step]<br>
Describe the action to perform on a single line.
   [Expected Result]<br>
The expected outcome documented on the following line.

Rationale: The `<br>` plus literal TAB convention preserves readable rendering in Markdown viewers and allows deterministic text-search and automated parsing tools to locate steps and results reliably.
